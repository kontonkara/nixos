# nixos

❄️ my nixos configuration

A flake for `alpha`, an MSI Alpha 17 C7VG (Ryzen 9 7940HX, Radeon 610M with an
RTX 4070 over PRIME): niri with the Noctalia shell, Home Manager, stylix
(Catppuccin Mocha with a peach accent) and sops-nix.

## Layout

```
flake.nix         inputs, and every host built from the modules below
hosts/alpha/      the machine
  default.nix       which modules are on, with their per-host values
  hardware.nix      generated by nixos-generate-config
  data.nix          the second NVMe: LUKS keyfile unlock of /data
  display.nix       the panel, as niri outputs and its stretched mode
  speakers-fir.wav  MSI's tuning of the speakers, from its Nahimic driver
modules/
  system/           NixOS: boot, kernel, storage, disko (the one-disk
                    layout), backup, graphics, network, secrets, services,
                    virtualisation, …
  programs/         programs with a system side: steam, gamescope, gamemode,
                    mcontrolcenter, yandex-browser-corporate, …
  home/             Home Manager, set from NixOS modules through
                    home-manager.users.<name>
    desktop/          niri, noctalia, stylix, gtk, xdg, dconf
    dotfiles/         one module per configured tool
    apps/             plain packages without settings
users/            accounts
pkgs/             local packages: yandex-browser-corporate, msi-ec,
                  msi-gpu-switcher, iwlwifi-lar
secrets/          sops-encrypted secrets
```

Every `default.nix` under `modules/` and `users/` is imported and does nothing
until its `modules.<path>.enable` is set; hosts turn modules on and pass them
their hardware facts (disks, PCI bus IDs, outputs). All `.nix` files in a
host's directory are imported for that host.

## Local patches

| Package | Patch | What it does |
| --- | --- | --- |
| niri | `modules/home/desktop/niri/niri-scaling-mode.patch` | `scaling-mode` output option and `niri msg output <name> scaling-mode` |
| noctalia | `modules/home/desktop/noctalia/hide-settings-button.patch` | no Settings button in the Control Center header |
| zed-editor | `modules/home/dotfiles/zed/patches/smooth-scroll.patch` | eased editor scrolling behind `smooth_scroll.enabled` (zed#44827) |
| mcontrolcenter | `modules/programs/mcontrolcenter/mcontrolcenter-sync-external-profile.patch` | follow the mode msi-ec sets by power source |
| mcontrolcenter | `modules/programs/mcontrolcenter/mcontrolcenter-fan-mode.patch` | advanced fan mode through msi-ec |
| sunshine | `modules/system/services/sunshine/unicode-via-wtype.patch` | text from Moonlight typed through wtype instead of Ctrl+Shift+U |
| wtype | `modules/system/services/sunshine/wtype-printable-keycodes.patch` | only printable-key keycodes, so Chromium doesn't read the first as Escape |
| iwlwifi | `pkgs/iwlwifi-lar/lar_disable.patch` | brings back the `lar_disable` module parameter |
